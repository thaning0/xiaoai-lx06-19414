# 支持与验证情况

## 硬件与固件

| 项目 | 实测配置 |
| --- | --- |
| 产品 | 小米小爱音箱 Pro（LX06） |
| 主板 | AS06，board_id=3 |
| NAND | FORESEE FSNS8A001G，128 MB 变体 |
| 原厂固件 | **1.94.14** |
| 内核 | 原厂 Linux 4.9.61，AArch64 |
| 开放音频软件包 | ARMv7 用户态 |
| USB 环境 | 原生 Windows，WinUSB + libusb-1.0 |

适配时保留本机 boot0/boot1、kernel、modules、firmware 和校准数据。其他主板、NAND 变体及固件版本尚未验证。

构建中用到的 **1.74.10** 仅用于提取上游软件包差分，不是本项目新增支持的固件版本，也不用于替换本机内核。

## 功能验证

下表记录了 2026-10-24 前在一台设备上的测试结果。

| 功能 | 结果 | 说明 |
| --- | --- | --- |
| Wi-Fi | 通过 | 已联网，重启后配置保留 |
| SSH | 通过 | 可登录并执行命令 |
| 网页与 API | 通过 | 页面、JavaScript 和 API 均返回成功 |
| 音量控制 | 通过 | 三路 mixer 可见，实测调整 69→60→69 |
| ALSA 播放 | 通过 | 两声测试音经实际听音确认 |
| 独立供电冷启动 | 通过一次 | 拔除 USB，断电 10 秒后接电，重新联网 |
| MPD / Shairport / UPMPDCLI / Snapclient / Bluetooth | 服务运行 | 尚未分别验证客户端完整播放流程 |
| 麦克风、AUX | 未测试 | — |
| 运行态 ADB | 未成功 | 未发现 adbd 进程，UDC 未绑定 |

冷启动验证中观察到新的 boot_id、uptime 38 秒、boot1、boot_failcnt 0、Wi-Fi COMPLETED 和 late-init 完成。之后约 30 秒内 uptime 从 117 增长到 132、147 秒。该记录是一轮实测，不代表长期稳定性测试。

## 实测镜像与公开源码

设备测试使用的是修复后的诊断 v2 镜像；网页随后通过 `/data` 文件、bind mount 和 `cron @reboot` 更新，断电启动后仍有效。

公开源码已将新网页直接纳入构建，并补齐构建报告校验。按当前源码重新生成的基础镜像和诊断镜像均通过离线检查，但尚未用这批产物重新刷入设备。两者与原实测镜像的哈希不同。

本方案替换原生小爱服务，不保留原小爱语音助手和原有配网流程。

## 构建验证

- 包含原厂输入的本地测试：117 项通过，0 项跳过。
- 不含原厂输入的测试：111 项通过，6 项原厂 fixture 测试跳过。
- 基础镜像与使用示例 Wi-Fi 的诊断镜像构建成功，当前网页文件已核对。
- 打包后重新解包，检查内容、权限、属主、符号链接和设备节点。
- 修改镜像并同步修改报告中的 size/hash，仍会被源码重放检查拒绝。

这些检查验证构建与工具行为。设备功能的状态以上面的实机测试表为准。
